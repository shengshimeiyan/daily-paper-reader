## 摘要
在多轮交互中运行的LLM智能体会将事实积累在外部记忆库中，并将其作为下游推理的前提进行复用。因此，在某一步写入的幻觉事实会作为错误前提存在于随后的每一步中，我们将这种失效模式称为记忆污染。现有的记忆管理主要解决检索和容量问题，而未涉及写入时的正确性；这种准入问题无法通过基于效用或新近度的标准来解决，且不受控制的污染会在长轨迹中不断累积。我们提出了ConsistencyGate，这是一种写入时的准入门控机制：在提交从上下文c中提取的候选事实m之前，该机制会向LLM查询K次以获得软支持分数，并且仅当该平均值超过阈值时才准许m写入。该机制与模型无关，无需微调，并且在针对延迟敏感部署的对数概率变体中可简化为单次前向传播。为了衡量在自然数据上的效果，我们通过在来自LoCoMo和MSC的长期对话中植入受控的单细节损坏，构建了两个真实对话基准，并用一个结构化合成语料库来补充它们，该语料库隔离了近oracle上界。在四种LLM骨干网络中，与全量写入基线相比，ConsistencyGate在每个基准上都降低了污染，其代价主要集中在源上下文中仅隐式陈述的事实上。我们发布了所有三个基准以及该门控机制的实现代码。

## Abstract
LLM agents that operate over many turns accumulate facts in an external memory store and reuse them as premises for downstream reasoning. A hallucinated fact written at one step therefore persists as a false premise for every subsequent step, a failure mode we call memory contamination. Existing memory management addresses retrieval and capacity but not write-time correctness; this admission problem cannot be solved by utility- or recency-based criteria, and uncontrolled contamination compounds across long trajectories. We propose ConsistencyGate, a write-time admission gate that, before committing a candidate fact m extracted from context c, queries the LLM K times for a soft support score and admits m only when the average exceeds a threshold. The mechanism is model-agnostic, requires no fine-tuning, and reduces to a single forward pass in a log-probability variant for latency-sensitive deployments. To measure the effect on natural data, we construct two real-conversation benchmarks (LoCoMo-Contam and MSC-Contam) by planting controlled single-detail corruptions in long-term conversations from LoCoMo and MSC, and complement them with a structured synthetic corpus (MemContam) that isolates a near-oracle upper bound. Across four LLM backbones, ConsistencyGate reduces contamination on every benchmark relative to a write-everything baseline, with the cost concentrated on facts that are stated only implicitly in the source context. We release all three benchmarks together with the gate implementation.

- **核心问题**：LLM（大语言模型）智能体在多轮交互中会将提取的事实存入外部记忆库，而写入的幻觉事实会作为错误前提持续污染后续的推理步骤，这种现象被定义为**记忆污染**。
- **现有研究的不足**：现有的记忆管理机制主要关注检索（如何找到记忆）和容量控制（如何淘汰记忆），而忽视了**写入时的正确性**。基于效用、新近度或相关性的准入标准无法区分正确事实与幻觉事实（因为幻觉事实往往同样具有相关性和新近度）。
- **整体含义**：记忆污染会随着交互轮次的增加而产生“级联效应”，导致错误不断放大。因此，必须在记忆写入阶段引入基于“事实正确性/支持度”的准入控制机制，这是现有记忆管理工具无法替代的。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程
- **核心思想**：提出 **ConsistencyGate**，一种写入时的准入门控机制。在将上下文 $c$ 中提取的候选事实 $m$ 写入记忆前，利用LLM自身对 $m$ 进行多次自一致性验证，只有当其受到源上下文的平均支持度超过阈值时才准许写入。该机制无需微调，与模型无关。
- **核心算法流程**：
  1. 给定候选事实 $m$ 和源上下文 $c$，使用软验证提示查询LLM $K$ 次，获取软支持分数 $s_k \in [0,1]$（0=完全矛盾，0.5=模糊，1=完全支持）。
  2. 计算一致性分数：$\hat{p}(m | c) = \frac{1}{K} \sum_{k=1}^{K} s_k$。
  3. 准入决策：若 $\hat{p}(m | c) \ge \tau$，则准许写入记忆 $M$。推荐默认配置为 $\tau = 0.7, K=5$。
- **高效单次前向传播变体**：
  - 针对延迟敏感场景，改用二元提示，通过单次前向传播获取 token 级别的对数概率来计算支持度：
    $\hat{p}_{log}(m | c) = \text{softmax}([\log p(\text{yes} | \text{prompt}), \log p(\text{no} | \text{prompt})])[0]$
  - 该变体速度提升 12-14 倍，特别适用于结构化上下文。
- **自适应阈值**：
  - 当无法针对特定部署调参时，阈值可根据记忆占用率动态调整：
    $\tau^*(|M|, C; \tau_{min}, \tau_{max}) = \tau_{min} + (\tau_{max} - \tau_{min}) \cdot \frac{|M|}{C}$
  - 记忆越满，阈值越严格。

### 6. 论文的主要结论与发现
- **显著降低污染**：ConsistencyGate 在所有基准和骨干网络上均降低了记忆污染。在合成数据 MemContam 上达到近 Oracle 表现（污染率降至 1.2%，召回率 100%）；在真实对话数据上，污染率相对降低 20%-62%。
- **污染级联效应的遏制**：随着交互轮次增加，WriteAll 的污染持续存在，而 ConsistencyGate 能使污染率随轮次稳步下降，下游 QA F1 显著提升。
- **隐式事实的代价**：方法的主要代价在于对隐式陈述事实的召回率较低（如 LoCoMo-Contam 上 Recall 仅为 0.58），因为验证器需要源上下文提供显式支持。
- **上下文结构决定变体选择**：LogProb 变体在结构化短上下文中表现完美且极速，但在长对话中不如软评分；软评分更适用于开放域对话。

### 7. 优点：方法或实验设计上的亮点
- **问题定义精准**：首次明确将“记忆污染”定义为写入时的准入问题，并论证了其与检索、容量问题的本质区别，证明了效用准则的失效。
- **即插即用与高效**：无需微调，与模型无关；提供了从高精度（K次采样）到低延迟（LogProb单次前向）的灵活部署方案。
- **基准测试贡献**：构建了首个包含受控单细节损坏的真实对话记忆污染基准，填补了该领域缺乏精细评估工具的空白。

### 8. 不足与局限
- **隐式/多跳推理事实的误拒**：对于需要跨轮次推理或隐式表达的正确事实，门控机制因无法在单一上下文中找到显式支持而将其错误拒绝，导致召回率下降。
- **一致性不等于正确性**：自一致性只是正确性的代理指标，如果幻觉事实符合模型内部先验但违背源上下文，验证器可能持续给出高分（假阳性），无法替代权威的事实核查。
- **LogProb 变体的适用范围受限**：高效的单次前向传播变体仅在干净的结构化数据上有效，在真实长对话场景下仍需依赖耗时的 K 次采样软评分。
- **额外推理开销**：默认配置下每个候选事实需要 5 次 LLM 调用，增加了写入时的延迟和能耗。
